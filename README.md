# Stack (TStack) + GoogleTest + CMake

Шаблонный стек с фиксированной вместимостью на C++, покрытый юнит-тестами Google Test и собранный через CMake.

## Структура проекта

```
├── CMakeLists.txt        # Сборочный файл CMake
├── include/
│   └── stack.hpp         # Реализация TStack<T> (header-only библиотека)
├── src/
│   └── main.cpp          # Демонстрационный пример использования
└── tests/
    └── stack_test.cpp    # Юнит-тесты Google Test (21 тест)
```

## Описание стека

`TStack<T>` — стек на статическом массиве с фиксированной вместимостью:

- `push(value)` — бросает `std::overflow_error` при переполнении;
- `pop()` / `top()` — бросают `std::underflow_error` при работе с пустым стеком;
- реализованы конструктор копирования и оператор присваивания (глубокое копирование, безопасное самоприсваивание);
- правила «большой тройки» соблюдены (деструктор освобождает память).

## Сборка и запуск

Google Test подтягивается автоматически через `FetchContent` (нужен интернет при первой конфигурации), либо можно использовать системную библиотеку.

```bash
# Конфигурация + сборка
cmake -S . -B build
cmake --build build

# Запуск демо
./build/stack_app

# Запуск тестов (через CTest)
cd build && ctest --output-on-failure

# Или напрямую
./build/stack_tests
```

Отключить сборку тестов: `cmake -S . -B build -DBUILD_TESTS=OFF`.

## Тесты

Покрыты: базовые операции (push/pop/top/size/empty), порядок LIFO, исключения (переполнение, пустой стек), конструктор копирования, оператор присваивания (включая самоприсваивание и присваивание пустого стека), работа с разными типами (`int`, `double`, `std::string`, `char`), а также интеграционный сценарий из `main`.
